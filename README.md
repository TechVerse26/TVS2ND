# Tech Verse

পিওর JavaScript ও CSS দিয়ে তৈরি সফটওয়্যার এজেন্সি ওয়েবসাইট — Firebase Authentication,
Firestore এবং এখন একটা সম্পূর্ণ **অ্যাডমিন প্যানেল** সহ, যেখান থেকে সাইটের প্রতিটা অংশ
(সার্ভিস, পোর্টফোলিও, টিম, প্রাইসিং, FAQ, বুকিং, ইউজার, সাইট সেটিংস — সব) ম্যানেজ করা যায়।
কোনো ফ্রেমওয়ার্ক/বিল্ড-স্টেপ নেই — সরাসরি ব্রাউজারে চলে।

## এই আপডেটে যা নতুন

- **অ্যাডমিন প্যানেল** (`admin.html`) — সার্ভিস, পোর্টফোলিও, কেস স্টাডি, টেস্টিমোনিয়াল, টিম,
  স্ট্যাটস কাউন্টার, প্রাইসিং প্যাকেজ, FAQ — সবকিছু যোগ/এডিট/মুছে ফেলা ও ক্রম পরিবর্তন করা যায়,
  কোনো কোড না ছুঁয়ে।
- **বুকিং ম্যানেজমেন্ট** — সব অনুরোধ এক জায়গায়, সার্চ/ফিল্টার, স্ট্যাটাস আপডেট (নতুন →
  যোগাযোগ করা হয়েছে → চলমান → সম্পন্ন/বাতিল)।
- **ইউজার ম্যানেজমেন্ট** — কাউকে অ্যাডমিন অ্যাক্সেস দেওয়া/বাদ দেওয়া যায় UI থেকেই।
- **সাইট সেটিংস** — হিরো টাইটেল/সাবটাইটেল, WhatsApp নম্বর, SEO বিবরণ — কোড এডিট না করেই বদলানো যায়।
- সাইটের সব কন্টেন্ট এখন **Firestore থেকে লোড হয়** (আগে `js/data.js`-এ হার্ডকোড করা ছিল)।
  `js/seed-data.js` এখন শুধু "ডিফল্ট কন্টেন্ট বসান" বাটনের জন্য নমুনা ডেটা হিসেবে আছে।
- ডিজাইন আরও ঝকঝকে করা হয়েছে — অ্যাভাটার সিস্টেম (ছবি/অক্ষর ফলব্যাক), বুকিং স্ট্যাটাস ব্যাজ,
  খালি-অবস্থার (empty state) আইকন, লোডিং স্কেলিটন — সব একই ডিজাইন টোকেন থেকে, কোনো
  গ্লো/শ্যাডো-হ্যালো ইফেক্ট ছাড়া।
- প্রোফাইল পেজ এখন একটা ছোট অ্যাকাউন্ট ড্যাশবোর্ড — মোট/চলমান/সম্পন্ন অনুরোধের সংখ্যা, আর
  অ্যাডমিন হলে সেখান থেকেই অ্যাডমিন প্যানেলের লিংক।
- সব ডাইনামিক টেক্সট এখন HTML-escape করে বসানো হয় — কারো লেখায় `&`, `<`, `>` থাকলেও
  লেআউট ভাঙবে না, আর পাবলিক বুকিং ফর্ম থেকে stored XSS-ও ঠেকানো হয়েছে।
- `sw.js`-এর অফলাইন cache লিস্টে `auth.js`/`firebase-config.js` বাদ পড়েছিল — সেটা ঠিক করা হয়েছে
  (আগে অফলাইনে প্রথমবার শেল ক্যাশ হলেও অ্যাপ ঠিকভাবে চলত না)।

## প্রজেক্ট স্ট্রাকচার

```
index.html            পাবলিক সাইট
admin.html             অ্যাডমিন প্যানেল
manifest.json / sw.js  PWA
firestore.rules         Firestore Security Rules
firestore.indexes.json  প্রয়োজনীয় কম্পোজিট ইনডেক্স
css/
  styles.css            মূল ডিজাইন সিস্টেম (পাবলিক সাইট + অ্যাডমিন দুটোতেই লোড হয়)
  admin.css              শুধু অ্যাডমিন প্যানেলের লেআউট (সাইডবার, টেবিল, ফর্ম)
js/
  firebase-config.js      Firebase প্রজেক্ট কনফিগ
  auth.js                 Authentication (ইমেইল/Google/GitHub) + admin-role হেল্পার
  content.js               পাবলিক সাইটের জন্য Firestore থেকে কন্টেন্ট পড়ার লেয়ার
  seed-data.js              ডিফল্ট/নমুনা কন্টেন্ট — শুধু "সিড" করার জন্য
  templates.js              কন্টেন্ট থেকে HTML বানানোর ফাংশন
  icons.js                  শেয়ার করা আইকন লাইব্রেরি (SVG)
  utils.js                  escapeHtml, তারিখ ফরম্যাট, বুকিং স্ট্যাটাস তালিকা ইত্যাদি
  router.js / toast.js / animations.js   অপরিবর্তিত হেল্পার
  app.js                     পাবলিক সাইটের মূল লজিক
  admin.js                   অ্যাডমিন প্যানেলের মূল লজিক (CRUD, বুকিং, ইউজার, সেটিংস)
```

## Firestore কালেকশন

| কালেকশন | কী আছে | কে লিখতে পারে |
|---|---|---|
| `services`, `portfolio`, `caseStudies`, `testimonials`, `team`, `stats`, `pricingPlans`, `faqItems` | সাইটের কন্টেন্ট, প্রতিটা ডকুমেন্টে একটা `order` নম্বর | শুধু অ্যাডমিন |
| `settings/site` | হিরো টেক্সট, WhatsApp নম্বর, SEO বিবরণ (একটামাত্র ডকুমেন্ট) | শুধু অ্যাডমিন |
| `users/{uid}` | নাম, ফোন, ছবি, `role` (থাকলে `"admin"`) | নিজের name/phone/photoURL নিজে, `role` শুধু অ্যাডমিন |
| `bookings/{id}` | বুকিং ফর্মের ডেটা + `status` | তৈরি: যে কেউ · পড়া: মালিক/অ্যাডমিন · আপডেট/মুছা: শুধু অ্যাডমিন |

## সেটআপ

Firebase প্রজেক্ট (`tvsaccount`) ও কনফিগ আগে থেকেই `js/firebase-config.js`-এ বসানো আছে।
নিচের ধাপগুলো [Firebase Console](https://console.firebase.google.com/) থেকে করতে হবে:

### ১. Authentication
Authentication → Sign-in method-এ গিয়ে **Email/Password**, **Google**, **GitHub** — এই তিনটা
প্রোভাইডার চালু করুন (GitHub-এর জন্য GitHub OAuth App-এর Client ID/Secret লাগবে)।

### ২. Firestore Database
Firestore Database তৈরি না থাকলে তৈরি করুন (production mode)।

### ৩. Security Rules বসানো
এই রিপোর জন্য `firestore.rules` ফাইলটা তৈরি করা আছে। Firebase Console → Firestore Database →
Rules ট্যাবে গিয়ে পুরো কন্টেন্ট paste করে **Publish** করুন। (Firebase CLI থাকলে
`firebase deploy --only firestore:rules` দিয়েও করা যায়।)

### ৪. কম্পোজিট ইনডেক্স
প্রোফাইল পেজে "আমার অনুরোধসমূহ" (নিজের বুকিং, `uid` দিয়ে ফিল্টার + তারিখ দিয়ে সাজানো)
লোড করতে একটা কম্পোজিট ইনডেক্স লাগে। দুইভাবে বসানো যায়:

- **সহজ:** সাইট থেকে প্রথমবার প্রোফাইল খুললে যদি ইনডেক্স না থাকে, ব্রাউজার কনসোলে Firebase
  নিজেই একটা লিংক দেখায় ("The query requires an index...") — সেই লিংকে ক্লিক করলেই
  এক ক্লিকে ইনডেক্স তৈরি হয়ে যায়।
- **CLI দিয়ে:** `firebase deploy --only firestore:indexes` (এই রিপোর `firestore.indexes.json`
  ব্যবহার করে)।

### ৫. প্রথম অ্যাডমিন সেট করা
নিরাপত্তার জন্য অ্যাপের ভেতর থেকে কেউ নিজেকে অ্যাডমিন বানাতে পারে না — প্রথম অ্যাডমিন
একবার ম্যানুয়ালি সেট করতে হয়:

1. সাইটে গিয়ে স্বাভাবিকভাবে **সাইন আপ** করুন (নিজের ইমেইল/Google/GitHub দিয়ে)।
2. Firebase Console → Firestore Database → `users` কালেকশনে গিয়ে নিজের ডকুমেন্টটা খুঁজুন
   (ইমেইল দেখে চেনা যাবে)।
3. একটা নতুন ফিল্ড যোগ করুন: `role` (type: **string**) → ভ্যালু `admin`।
4. সাইটে রিফ্রেশ দিলে প্রোফাইল পেজে "অ্যাডমিন প্যানেল" লিংক দেখা যাবে।

এরপর থেকে অন্য কাউকে অ্যাডমিন বানাতে চাইলে অ্যাডমিন প্যানেল → ইউজার থেকেই করা যাবে,
Firebase Console-এ ফিরে যাওয়া লাগবে না।

### ৬. ডিফল্ট কন্টেন্ট বসানো
অ্যাডমিন প্যানেলে ঢুকে ড্যাশবোর্ডে "ডিফল্ট কন্টেন্ট বসান" বাটনে ক্লিক করলে নমুনা সার্ভিস,
পোর্টফোলিও, টিম ইত্যাদি একবারে Firestore-এ বসে যায় — এরপর সেখান থেকেই এডিট করে নিজের
আসল কন্টেন্ট বসিয়ে নেওয়া যায়। যেসব সেকশনে আগে থেকে কিছু আছে, সেগুলো এই বাটনে টাচ হয় না।

## লোকালি রান করা

`index.html` সরাসরি ব্রাউজারে (`file://`) খুললে ES module/Firestore কাজ করবে না — একটা
লোকাল সার্ভার লাগবে, যেমন:

```
npx serve .
```

বা VS Code-এর Live Server এক্সটেনশন দিয়ে।

## ডিপ্লয়

যেকোনো স্ট্যাটিক হোস্টিং (Firebase Hosting, Netlify, Vercel) দিয়ে ডিপ্লয় করা যায় — পুরো
ফোল্ডারটাই আপলোড করলেই হবে (`index.html` আর `admin.html` দুটোই থাকা জরুরি)। Firebase
Hosting ব্যবহার করলে:

```
firebase init hosting
firebase deploy
```

## কাস্টমাইজেশন নোট

- **হিরো টাইটেলে হাইলাইট রঙ:** অ্যাডমিন প্যানেল → সেটিংসে হিরো টাইটেলে কোনো অংশ
  `**এভাবে**` ডাবল-স্টার দিয়ে ঘিরে দিলে সেটা অ্যাকসেন্ট রঙে (মিন্ট) হাইলাইট হয়ে দেখাবে।
- **ছবি:** পোর্টফোলিও/টিম/টেস্টিমোনিয়ালে ছবি দেখাতে চাইলে ছবির একটা পাবলিক URL বসাতে হবে
  (যেমন imgur, বা নিজের হোস্টিং থেকে) — এই প্রজেক্টে ফাইল আপলোড/Firebase Storage যুক্ত করা
  হয়নি, তাই সরাসরি ফাইল আপলোডের অপশন নেই।
- **আইকন:** সার্ভিস কার্ডের আইকন একটা নির্দিষ্ট (কিন্তু বেশ বড়) তালিকা থেকে বেছে নিতে হয়
  (`js/icons.js`) — সবগুলো একই স্ট্রোক-স্টাইলে আঁকা, যাতে নতুন আইকন যোগ করলেও ডিজাইন না ভাঙে।
