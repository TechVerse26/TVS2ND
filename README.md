# Tech Verse

পিওর JavaScript ও CSS দিয়ে তৈরি সফটওয়্যার এজেন্সি ওয়েবসাইট — Firebase Authentication,
Firestore এবং এখন একটা সম্পূর্ণ **অ্যাডমিন প্যানেল** সহ, যেখান থেকে সাইটের প্রতিটা অংশ
(সার্ভিস, পোর্টফোলিও, টিম, প্রাইসিং, FAQ, বুকিং, ইউজার, সাইট সেটিংস — সব) ম্যানেজ করা যায়।
কোনো ফ্রেমওয়ার্ক/বিল্ড-স্টেপ নেই — সরাসরি ব্রাউজারে চলে।

## নতুন (v01.00.03) — কমিউনিটি + আইসোলেশনড Firestore

- **কমিউনিটি / আলোচনা সেকশন** (`#community`) — ফিড (২০টা করে লোড + "আরও দেখুন"), ক্যাটাগরি, আলোচনার পাতায়
  রিপ্লাই (কাউকে নির্দিষ্ট করে উত্তরসহ), লাইক, শেয়ার/লিংক কপি, এডিট (`সম্পাদিত` চিহ্ন), মুছা (soft-delete),
  রিপোর্ট ও অ্যাডমিন মডারেশন। বিদ্যমান ডিজাইন টোকেন/কম্পোনেন্ট পুনর্ব্যবহার — নতুন কোনো ডিজাইন সিস্টেম নেই।
  বিস্তারিত নিচে **"কমিউনিটি"** অংশে।
- **Firestore আইসোলেশন** — `firestore.rules` এখন শুধু Tech Verse-এর: কোর্স/এক্সাম/ফ্ল্যাশকার্ড/Learning Hub/
  অন্য ডিসকাশন সিস্টেমের কোনো কালেকশন বা rule নেই; ওপেন write নেই; শেষে `allow read, write: if false`।
  সব ডেটা এখন **`tvProject/main/**`** নেমস্পেসে (পাথ এক জায়গায় — `js/tv-db.js`)।
- ⚠️ **ডিপ্লয়ের আগে অবশ্যই পড়ুন:** পুরোনো ডেটা (users, bookings, কন্টেন্ট) পুরোনো পাথে আছে —
  **"পুরোনো ডেটা নতুন নেমস্পেসে আনা"** অংশ অনুযায়ী মাইগ্রেট না করলে সাইট খালি দেখাবে, আর
  নতুন rules একটা Firebase প্রজেক্টের **পুরো** Firestore rules বদলে দেয় — তাই শুধু Tech Verse-এর নিজস্ব
  Firebase প্রজেক্টে ডিপ্লয় করুন।

## ডিজাইন আপডেট — "Sky" (এই ভার্সনে যা নতুন)

- **প্রোফাইল এখন একটা স্লাইডার মেনু** — হেডারের অ্যাভাটার ট্যাপ করলে ডান দিক থেকে স্লাইড করে খোলে
  (`js/drawer.js` + `css/drawer.css`)। ভেতরে: ছবি বদলানো, **Edit profile / Code / Course** বাটন,
  মোট/চলমান/সম্পন্ন স্ট্যাটস, আর **About / My Project / Account Setting**। অ্যাডমিন হলে **Admin** বাটনও আসে।
  মোবাইলের ☰ বাটন একই স্লাইডারে সাইট মেনু খোলে (লগইন না থাকলেও)।
  - স্ট্যাটস টাইল ট্যাপ করলে My Project-এ ওই ফিল্টারে খোলে; ব্রাউজার/অ্যান্ড্রয়েডের Back চাপলে আগে
    স্লাইডার বা সাব-প্যানেল বন্ধ হয় (PWA-তে অ্যাপ থেকে বেরিয়ে যায় না); Esc ও ডান দিকে সোয়াইপেও বন্ধ হয়।
  - পুরোনো `#profile` লিংক (যেমন অ্যাডমিন গেট থেকে) এখনও কাজ করে — স্লাইডার খুলে দেয়।
- **Code ও Course বাটনের লিংক বসাতে**: অ্যাডমিন প্যানেল → **সেটিংস** → "প্রোফাইল স্লাইডারের লিংক"
  (`codeUrl`, `courseUrl`)। কোডে ডিফল্ট দিতে চাইলে `js/seed-data.js`-এর `defaultSettings`-এ বসান।
  লিংক না বসানো পর্যন্ত বাটন দুটো দেখা যায়, ট্যাপ করলে একটা বার্তা আসে।
- **প্রোফাইল ছবি** — নিজের ফোন/কম্পিউটার থেকে ছবি বেছে নিলে সেটা মাঝখান থেকে বর্গাকারে কেটে ২৫৬×২৫৬
  করে (সাধারণত ২০–৩০KB) `users/{uid}.avatarData`-তে সেভ হয় — আলাদা Storage বা বাড়তি রুলস লাগে না।
  Google/GitHub-এর ছবি থাকলে সেটা ডিফল্ট; নিজের ছবি দিলে সেটাই দেখায়।
- **নতুন ডিজাইন** — TVsite লোগোর নীল রঙ ও নরম টিন্টেড সারফেস (নীল/পুদিনা/বেগুনি), পিল-ব্যাজ,
  গোল আইকন-ডিস্ক। কোনো গ্লো নেই। ফন্ট: Plus Jakarta Sans + Hind Siliguri (বাংলা)।
- **থিম**: লাইট ডিফল্ট, ডার্ক/সিস্টেম বেছে নেওয়া যায় (হেডারের বাটন বা Account Setting থেকে)।
- **নতুন ফুটার — Quick Links + Contact Us** (`js/footer.js`, `css/footer.css`):
  - **Contact Us**: Facebook, YouTube Channel, WhatsApp, দুটো ইমেইল, Call — ট্যাপ করলে যার যা কাজ:
    লিংক নতুন ট্যাবে খোলে, WhatsApp আগে থেকে লেখা মেসেজসহ খোলে, ইমেইল মেইল অ্যাপ খোলে, Call সরাসরি
    ডায়াল করে। ইমেইল/ফোনের পাশে কপি বাটনও আছে।
  - **সব তথ্য কোডে, অ্যাডমিন প্যানেলে নয়** — `js/contact.js` একটাই ফাইল; ফোন/ইমেইল/লিংক বদলাতে শুধু ওটা
    এডিট করুন। ফুটার, ডানদিকের WhatsApp বাটন ও Help & Support সব ওখান থেকে পড়ে। ফুটার `js/site.js`
    দিয়ে রেন্ডার হয়, যেটা Firebase-এর ওপর নির্ভর করে না — তাই অফলাইনে বা Firebase-এর ফাইল লোড না হলেও
    কাজ করে (Service Worker ক্যাশসহ পরীক্ষা করা)।
  - **Quick Links**: About Us, Privacy Policy, Terms & Conditions, Help & Support, Credits — প্রতিটা একটা
    তথ্য-শিটে খোলে (`js/info.js`; লেখাগুলো ওই ফাইলেই)। URL-এ `#about`, `#privacy`, `#terms`, `#help`,
    `#credits` বসে, তাই সরাসরি লিংক শেয়ার করা যায় (যেমন Google/GitHub অ্যাপ সেটআপে Privacy Policy-র লিংক)।
    ⚠️ Privacy/Terms সাধারণ খসড়া — প্রকাশের আগে নিজের বাস্তবতার সাথে মিলিয়ে নিন (আইনজীবীকে দেখানো ভালো)।
    ⚠️ Privacy-তে লেখা আছে "কোনো বিজ্ঞাপন-কুকি বা থার্ড-পার্টি অ্যানালিটিক্স ট্র্যাকার নেই" — এখনকার কোডে এটা সত্যি;
    ভবিষ্যতে অ্যানালিটিক্স/ট্র্যাকার যোগ করলে `js/info.js`-এর privacyPage-এর "Cookies" অংশ অবশ্যই বদলাবেন।
  - **Quick Links-এর সব লেখা এখন ইংরেজিতে** (ফুটারের ব্লার্ব ও নিচের লাইনসহ) এবং **কোনো টেক-স্ট্যাকের নাম নেই**
    (JavaScript/CSS/Firebase/লাইব্রেরি — ক্লায়েন্টকে জানানোর দরকার নেই বলে ইচ্ছাকৃত)। লেখা বদলাতে `js/info.js`-এর
    `aboutPage`, `privacyPage`, `termsPage`, `helpPage`, `creditsPage` এডিট করুন; আইনি তারিখ বদলাতে `UPDATED_ISO`।
    Privacy/Terms/Help-এ ইউজারের সামনের বাটন-নামের (My Project, Edit profile, Account Setting) উল্লেখ আছে — UI বদলালে এগুলোও মিলিয়ে নিন।
  - **WhatsApp আইকন**: অফিসিয়াল গ্লিফ (`js/icons.js`-এর `WHATSAPP_PATH`)। ফ্লোট বাটন ও বুকিং-সাইডের আইকন `index.html`-এ
    inline, তাই path বদলাতে হলে ওই দুই জায়গাতেও বদলান। আগে-থেকে-লেখা মেসেজ ও ইমেইল সাবজেক্ট এখন ইংরেজি (`js/contact.js`)।
  - অ্যাডমিন সেটিংস থেকে WhatsApp নম্বর/মেসেজের ঘর সরিয়ে দেওয়া হয়েছে (এখন কোডে)।
- বুকিং ফর্মে লগইন থাকলে নাম/ইমেইল/ফোন আগেই ভরা থাকে; ধাপ যাচাই আরও কড়া; ব্যাকগ্রাউন্ডে স্ক্রল-স্পাই
  (বর্তমান সেকশন হাইলাইট); পাসওয়ার্ড দেখা/লুকানো বাটন; মোবাইলে লগইন মডাল নিচ থেকে ওঠে।
- `sw.js` এখন নিজের ফাইলের জন্য **নেটওয়ার্ক-ফার্স্ট** (ডিজাইন আপডেট করলে ইউজার সাথে সাথে নতুনটা পায়),
  অফলাইনে ক্যাশ থেকে চলে। ক্যাশ ভার্সন `v6`।
- অ্যাডমিন প্যানেলও একই ডিজাইনে; ড্যাশবোর্ডের ওভারভিউ তালিকা এখন মোবাইলেও দেখায়।

## আগের আপডেটে যা এসেছিল


- **অ্যাডমিন প্যানেল** (`admin.html`) — সার্ভিস, পোর্টফোলিও, কেস স্টাডি, টেস্টিমোনিয়াল, টিম,
  স্ট্যাটস কাউন্টার, প্রাইসিং প্যাকেজ, FAQ — সবকিছু যোগ/এডিট/মুছে ফেলা ও ক্রম পরিবর্তন করা যায়,
  কোনো কোড না ছুঁয়ে।
- **বুকিং ম্যানেজমেন্ট** — সব অনুরোধ এক জায়গায়, সার্চ/ফিল্টার, স্ট্যাটাস আপডেট (নতুন →
  যোগাযোগ করা হয়েছে → চলমান → সম্পন্ন/বাতিল)।
- **ইউজার ম্যানেজমেন্ট** — কাউকে অ্যাডমিন অ্যাক্সেস দেওয়া/বাদ দেওয়া যায় UI থেকেই।
- **সাইট সেটিংস** — হিরো টাইটেল/সাবটাইটেল, SEO বিবরণ, Code/Course লিংক — কোড এডিট না করেই বদলানো যায়। (যোগাযোগের তথ্য নয় — ওগুলো `js/contact.js`-এ।)
- সাইটের সব কন্টেন্ট এখন **Firestore থেকে লোড হয়** (আগে `js/data.js`-এ হার্ডকোড করা ছিল)।
  `js/seed-data.js` এখন শুধু "ডিফল্ট কন্টেন্ট বসান" বাটনের জন্য নমুনা ডেটা হিসেবে আছে।
- ডিজাইন আরও ঝকঝকে করা হয়েছে — অ্যাভাটার সিস্টেম (ছবি/অক্ষর ফলব্যাক), বুকিং স্ট্যাটাস ব্যাজ,
  খালি-অবস্থার (empty state) আইকন, লোডিং স্কেলিটন — সব একই ডিজাইন টোকেন থেকে, কোনো
  গ্লো/শ্যাডো-হ্যালো ইফেক্ট ছাড়া।
- প্রোফাইল পেজ এখন একটা ছোট অ্যাকাউন্ট ড্যাশবোর্ড — মোট/চলমান/সম্পন্ন অনুরোধের সংখ্যা, আর
  অ্যাডমিন হলে সেখান থেকেই অ্যাডমিন প্যানেলের লিংক।
- সব ডাইনামিক টেক্সট এখন HTML-escape করে বসানো হয় — কারো লেখায় `&`, `<`, `>` থাকলেও
  লেআউট ভাঙবে না, আর পাবলিক বুকিং ফর্ম থেকে stored XSS-ও ঠেকানো হয়েছে।
- `sw.js`-এর অফলাইন cache লিস্টে `auth.js`/`firebase-config.js` বাদ পড়েছিল — সেটা ঠিক করা হয়েছে
  (আগে অফলাইনে প্রথমবার শেল ক্যাশ হলেও অ্যাপ ঠিকভাবে চলত না)।

## Firestore কালেকশন

সব ডেটা একটা নেমস্পেসে — `tvProject/main/…`। এর বাইরের যেকোনো পাথ rules-এ **default-deny**।

| পাথ (`tvProject/main/` এর নিচে) | কী আছে | কে কী করতে পারে |
|---|---|---|
| `services`, `portfolio`, `caseStudies`, `testimonials`, `team`, `stats`, `pricingPlans`, `faqItems` | সাইটের কন্টেন্ট, প্রতিটায় `order` | পড়া: সবাই · লেখা: শুধু অ্যাডমিন |
| `settings/site` | হিরো টেক্সট, SEO, লিংক (একটামাত্র ডকুমেন্ট) | পড়া: সবাই · লেখা: শুধু অ্যাডমিন |
| `users/{uid}` | নাম, ফোন, `bio`, ছবি (`avatarData`, কমিউনিটির জন্য ছোট `avatarThumb`), `isAdmin`, `communityBlocked` | নিজের প্রোফাইল-ফিল্ড নিজে; `isAdmin`/`communityBlocked` শুধু অ্যাডমিন; পড়া: নিজে + অ্যাডমিন |
| `bookings/{id}` | বুকিং ফর্মের ডেটা + `status` | তৈরি: যে কেউ (কঠোর ভ্যালিডেশন) · পড়া: মালিক/অ্যাডমিন · `status` বদল/মুছা: অ্যাডমিন |
| `categories/{slug}` | কমিউনিটির ক্যাটাগরি (`name`, `order`, `active`) | পড়া: সবাই · লেখা: অ্যাডমিন |
| `discussions/{id}` | আলোচনা (`title`, `body`, `category`, `status`, `likedBy`, `likeCount`, `replyCount`…) | নিচে "কমিউনিটি" |
| `discussions/{id}/replies/{rid}` | রিপ্লাই | নিচে "কমিউনিটি" |
| `reports/{uid_targetType_targetId}` | রিপোর্ট | তৈরি: লগইন করা ইউজার (ডুপ্লিকেট অসম্ভব) · পড়া/রিভিউ: অ্যাডমিন |

অ্যাডমিন = `tvProject/main/users/{uid}.isAdmin == true` — শুধু এই প্রজেক্টের নিজস্ব `users`। এটা **rules-এই**
যাচাই হয় (UI-তে অ্যাডমিন বাটন লুকানো শুধু সুবিধার জন্য)।

## সেটআপ

Firebase প্রজেক্ট (`tvsitesofficial`) ও কনফিগ আগে থেকেই `js/firebase-config.js`-এ বসানো আছে।
নিচের ধাপগুলো [Firebase Console](https://console.firebase.google.com/) থেকে করতে হবে:

### ১. Authentication
Authentication → Sign-in method-এ গিয়ে **Email/Password**, **Google**, **GitHub** — এই তিনটা
প্রোভাইডার চালু আছে কিনা দেখে নিন (GitHub-এর জন্য GitHub OAuth App-এর Client ID/Secret লাগে)।

### ২. Security Rules ডিপ্লয় — ⚠️ প্রজেক্টের পুরো Firestore rules বদলে যায়
`firestore.rules` শুধু Tech Verse-এর। Firebase প্রজেক্টে একটাই rules-ফাইল থাকে — এটা ডিপ্লয় করলে আগের
সব rule (অন্য কোনো অ্যাপের হলে সেগুলোসহ) **মুছে** এটা বসে যায়। তাই:

- শুধু Tech Verse-এর নিজস্ব Firebase প্রজেক্টে (`tvsitesofficial`) ডিপ্লয় করুন। যদি এই প্রজেক্টে এখনো অন্য
  কোনো অ্যাপ চলে, সেটা এই rules-এ বন্ধ হয়ে যাবে — তখন Tech Verse-এর জন্য আলাদা Firebase প্রজেক্ট (বা আলাদা
  named Firestore database) নিন।
- ডিপ্লয়ের আগে নিচের **মাইগ্রেশন** শেষ করুন, নইলে সাইট পুরোনো ডেটা দেখতে পাবে না।
- কমান্ড (Firebase CLI): `firebase deploy --only firestore:rules,firestore:indexes` — অথবা Console → Firestore →
  Rules ট্যাবে `firestore.rules` পুরোটা paste করে **Publish**।
- ডিপ্লয়ের আগে `tests/`-এর Emulator-টেস্ট চালিয়ে নিতে পারেন (নিচে "Security Rules টেস্ট")।

### ৩. কম্পোজিট ইনডেক্স
`firestore.indexes.json`-এ এখন ৫টা ইনডেক্স — প্রতিটা বাস্তবে ব্যবহৃত একটা কোয়েরির জন্য:

| কালেকশন | ফিল্ড | কোয়েরি |
|---|---|---|
| `bookings` | `uid` ↑, `createdAt` ↓ | প্রোফাইলে "আমার অনুরোধসমূহ" |
| `discussions` | `status` ↑, `createdAt` ↓ | ফিড (সব ক্যাটাগরি) ও অ্যাডমিনের স্ট্যাটাস-ফিল্টার |
| `discussions` | `status` ↑, `category` ↑, `createdAt` ↓ | ক্যাটাগরি-ভিত্তিক ফিড |
| `replies` | `status` ↑, `createdAt` ↑ | আলোচনার রিপ্লাই তালিকা |
| `reports` | `status` ↑, `createdAt` ↓ | অ্যাডমিনের "খোলা রিপোর্ট" |

ডিপ্লয়: `firebase deploy --only firestore:indexes` (তৈরি হতে কয়েক মিনিট লাগে)। এই প্রজেক্টে শুধু Tech Verse-এর
ইনডেক্স থাকবে — CLI ডিপ্লয় ফাইলে না-থাকা ইনডেক্স মুছে দিতে পারে, তাই অন্য অ্যাপের ইনডেক্স এই প্রজেক্টে রাখবেন না।

### ৪. প্রথম অ্যাডমিন সেট করা
অ্যাডমিন-অনুমতি **শুধু** `tvProject/main/users/{uid}.isAdmin` দিয়ে — অন্য কোনো অ্যাপের অ্যাডমিন এখানে স্বয়ংক্রিয়ভাবে
অ্যাডমিন হয় না। প্রথম অ্যাডমিন একবার ম্যানুয়ালি:

1. সাইটে গিয়ে স্বাভাবিকভাবে **সাইন আপ/লগইন** করুন (এতে `tvProject/main/users/{uid}` ডকুমেন্ট তৈরি হয়)।
2. Firebase Console → Firestore Database → `tvProject` → `main` → `users`-এ নিজের ডকুমেন্টটা খুঁজুন (ইমেইল দেখে)।
3. `isAdmin` ফিল্ডটা `false` থেকে `true` করুন (type: **boolean**)। (মাইগ্রেশন স্ক্রিপ্টে `--admin you@example.com` দিলে এটা অটো হয়।)
4. রিফ্রেশ দিলে প্রোফাইলে "অ্যাডমিন প্যানেল" লিংক আসবে। এরপর অন্যদের অ্যাডমিন বানানো/কমিউনিটি-ব্লক করা অ্যাডমিন প্যানেল → ইউজার থেকেই।

### ৫. ডিফল্ট কন্টেন্ট বসানো
অ্যাডমিন প্যানেলে ঢুকে ড্যাশবোর্ডে "ডিফল্ট কন্টেন্ট বসান" বাটনে ক্লিক করলে নমুনা সার্ভিস,
পোর্টফোলিও, টিম ইত্যাদি একবারে Firestore-এ বসে যায় — এরপর সেখান থেকেই এডিট করে নিজের
আসল কন্টেন্ট বসিয়ে নেওয়া যায়। যেসব সেকশনে আগে থেকে কিছু আছে, সেগুলো এই বাটনে টাচ হয় না।

- **রঙ বদলাতে:** সব রঙ `css/styles.css`-এর শুরুর টোকেন ব্লকে (`--accent`, `--blue-*`, `--mint-*` …)।
  একটা জায়গায় বদলালেই সাইট, ফুটার, স্লাইডার ও অ্যাডমিন — সবখানে বদলে যাবে।
- **আইকন:** সার্ভিস কার্ডের আইকন একটা নির্দিষ্ট (কিন্তু বেশ বড়) তালিকা থেকে বেছে নিতে হয়
  (`js/icons.js`) — সবগুলো একই স্ট্রোক-স্টাইলে আঁকা, যাতে নতুন আইকন যোগ করলেও ডিজাইন না ভাঙে।

## কমিউনিটি (আলোচনা)

**কোথায়:** হেডারের "কমিউনিটি" লিংক (`#community`); একটা আলোচনার সরাসরি লিংক `…/index.html#community/{id}` — শেয়ার বাটন এটাই কপি/শেয়ার করে।
**কীভাবে লোড হয়:** `js/community-entry.js` (Firebase-মুক্ত) হ্যাশ ধরে; কমিউনিটির কোড ও Firebase শুধু কমিউনিটি খুললে `import()` হয়।
Firebase/ইন্টারনেট না থাকলে কমিউনিটির জায়গায় "অফলাইন + আবার চেষ্টা করুন" দেখায়, বাকি সাইট স্বাভাবিক চলে।

**ডেটা-মডেল ও নিয়ম (সবই `firestore.rules`-এ বলবৎ):**
- পড়া: লগইন ছাড়াও সবাই শুধু `status == "active"` কনটেন্ট দেখে; লুকানো/মুছে-ফেলা শুধু মালিক ও অ্যাডমিন। লগইন-ছাড়া পড়া বন্ধ করতে rules-এর `canReadContent()`-এ `isSignedIn() &&` যোগ করুন।
- লেখা/লাইক/রিপোর্ট: লগইন + প্রোফাইল আছে + `communityBlocked` নয়। `uid`, `authorName`, `authorAvatar` ক্লায়েন্টের মানে ভরসা নয় — rules এগুলোকে `users/{uid}` ডকুমেন্টের সাথে মেলায়।
- সময়: `createdAt`/`updatedAt`/`editedAt` সবসময় সার্ভার-টাইমস্ট্যাম্প (`request.time`)। `uid`, `createdAt`, `category`, লেখকের তথ্য, কাউন্টার, `status` মালিক বদলাতে পারে না।
- এডিট: মালিক শুধু `title`/`body`; `editedAt` সার্ভার-টাইম। মুছা: মালিকের "মুছুন" = `status: "deleted"` (soft-delete); হার্ড-ডিলিট **কারো জন্যই** বন্ধ।
- লাইক: `likedBy` (uid-এর তালিকা) + `likeCount`; rules শুধু কলারের **নিজের** uid যোগ/বাদ এবং `likeCount == likedBy.size()` মানে — ডুপ্লিকেট/অন্যের uid/জাল সংখ্যা অসম্ভব (সর্বোচ্চ ৫০০০ লাইক/ডকুমেন্ট)।
- রিপ্লাই-কাউন্ট: `replyCount` বদলাতে হলে **একই batch-এ** সত্যিকারের রিপ্লাই তৈরি/নিষ্ক্রিয় হতে হবে (`replySyncId`) — rules `getAfter()` দিয়ে মেলায়; তাই জাল কাউন্ট অসম্ভব।
- রিপোর্ট: ডকুমেন্ট-id = `{reporterUid}_{discussion|reply}_{targetId}` — একই কনটেন্টে দ্বিতীয় রিপোর্ট = update, যা শুধু অ্যাডমিন পারে ⇒ ডুপ্লিকেট-স্প্যাম অসম্ভব।
- পেজিনেশন: ফিডে `limit(20)` + `startAfter`; rules-এ পাবলিক লিস্ট-কোয়েরিতে `limit ≤ 50` বাধ্যতামূলক (পুরো ডেটাবেস একসাথে টানা যায় না)।

**ক্যাটাগরি:** `categories/{slug}` — অ্যাডমিন প্যানেল → কমিউনিটি মডারেশন → "ক্যাটাগরি" থেকে নতুন যোগ/নাম বদল/ক্রম/নিষ্ক্রিয়।
প্রথমবার **"ডিফল্ট ক্যাটাগরি বসান"** চাপুন (General, Web Development, JavaScript, Firebase, UI/UX, Programming, Project Help, Tech Verse, Other) — নইলে পোস্ট করা যাবে না।

**অ্যাডমিন মডারেশন** (`admin.html#community`): রিপোর্ট রিভিউ (রিভিউ শুরু/সমাধান/বাতিল, রিপোর্ট থেকেই কনটেন্ট লুকানো/মুছা), সব আলোচনা (স্ট্যাটাস-ফিল্টার; লুকান/মুছুন/পুনঃপ্রকাশ; রিপ্লাই-ধরে-ধরে মডারেশন), ক্যাটাগরি, এবং ইউজার-পেজে **"কমিউনিটি ব্লক"**।

**অফলাইন/প্রাইভেসি সিদ্ধান্ত:** কমিউনিটির ডেটা Firestore-এর offline persistence-এ বা Service Worker ক্যাশে **রাখা হয় না** (শেয়ারড ডিভাইসে লগআউটের পরও কারো লেখা/প্রোফাইল-তথ্য থেকে যাওয়া ঠেকাতে)। শুধু অ্যাপ-শেল ক্যাশ হয়; অফলাইনে ফিড লোড না হয়ে retry-সহ বার্তা দেখায়।

## পুরোনো ডেটা নতুন নেমস্পেসে আনা

আগের ভার্সনে ডেটা root-পাথে (`users`, `bookings`, `services`…) ছিল; এখন সব `tvProject/main/…`-এ। ডিপ্লয়ের আগে:

1. Firebase Console → Project settings → Service accounts → **Generate new private key** (JSON; কখনো কমিট করবেন না)।
2. `cd scripts && npm init -y && npm i firebase-admin`
3. ড্রাই-রান: `node migrate-to-tvproject.mjs --key ./serviceAccount.json --dry-run`
4. আসল কপি: `node migrate-to-tvproject.mjs --key ./serviceAccount.json --admin you@example.com`
   — শুধু Tech Verse-এর ফিল্ড কপি হয়; `isAdmin` কপি হয় না (শুধু `--admin` দেওয়া ইমেইল অ্যাডমিন হয়); পুরোনো ডেটা মোছা হয় না।
5. তারপর rules + indexes ডিপ্লয়, সাইট ও অ্যাডমিন প্যানেল চেক, এবং শেষে অ্যাডমিন প্যানেল → কমিউনিটি → ডিফল্ট ক্যাটাগরি।

(কন্টেন্ট সিড করতে চাইলে মাইগ্রেশন ছাড়া অ্যাডমিন ড্যাশবোর্ডের "ডিফল্ট কন্টেন্ট বসান" বাটনও নতুন নেমস্পেসে বসায়।)
