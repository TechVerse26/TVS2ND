# Tech Verse

পিওর JavaScript ও CSS দিয়ে তৈরি সফটওয়্যার এজেন্সি ওয়েবসাইট — Firebase Authentication,
Firestore এবং এখন একটা সম্পূর্ণ **অ্যাডমিন প্যানেল** সহ, যেখান থেকে সাইটের প্রতিটা অংশ
(সার্ভিস, পোর্টফোলিও, টিম, প্রাইসিং, FAQ, বুকিং, ইউজার, সাইট সেটিংস — সব) ম্যানেজ করা যায়।
কোনো ফ্রেমওয়ার্ক/বিল্ড-স্টেপ নেই — সরাসরি ব্রাউজারে চলে।

## ডিজাইন আপডেট — "Sky" (এই ভার্সনে যা নতুন)

- **প্রোফাইল এখন একটা স্লাইডার মেনু** — হেডারের অ্যাভাটার ট্যাপ করলে ডান দিক থেকে স্লাইড করে খোলে
  (`js/drawer.js` + `css/drawer.css`)। ভেতরে: ছবি বদলানো, **Edit profile / Code / Course** বাটন,
  মোট/চলমান/সম্পন্ন স্ট্যাটস, আর **About / My Project / Account Setting**। অ্যাডমিন হলে **Admin** বাটনও আসে।
  মোবাইলের ☰ বাটন একই স্লাইডারে সাইট মেনু খোলে (লগইন না থাকলেও)।
  - স্ট্যাটস টাইল ট্যাপ করলে My Project-এ ওই ফিল্টারে খোলে; ব্রাউজার/অ্যান্ড্রয়েডের Back চাপলে আগে
    স্লাইডার বা সাব-প্যানেল বন্ধ হয় (PWA-তে অ্যাপ থেকে বেরিয়ে যায় না); Esc ও ডান দিকে সোয়াইপেও বন্ধ হয়।
  - পুরোনো `#profile` লিংক (যেমন অ্যাডমিন গেট থেকে) এখনও কাজ করে — স্লাইডার খুলে দেয়।
- **Code ও Course বাটনের লিংক বসাতে**: অ্যাডমিন প্যানেল → **সেটিংস** → "প্রোফাইল স্লাইডারের লিংক"
  (`codeUrl`, `courseUrl`)। কোডে ডিফল্ট দিতে চাইলে `js/seed-data.js`-এর `defaultSettings`-এ বসান।
  লিংক না বসানো পর্যন্ত বাটন দুটো দেখা যায়, ট্যাপ করলে একটা বার্তা আসে।
- **প্রোফাইল ছবি** — নিজের ফোন/কম্পিউটার থেকে ছবি বেছে নিলে সেটা মাঝখান থেকে বর্গাকারে কেটে ২৫৬×২৫৬
  করে (সাধারণত ২০–৩০KB) `users/{uid}.avatarData`-তে সেভ হয় — আলাদা Storage বা বাড়তি রুলস লাগে না।
  Google/GitHub-এর ছবি থাকলে সেটা ডিফল্ট; নিজের ছবি দিলে সেটাই দেখায়।
- **নতুন ডিজাইন** — TVsite লোগোর নীল রঙ ও নরম টিন্টেড সারফেস (নীল/পুদিনা/বেগুনি), পিল-ব্যাজ,
  গোল আইকন-ডিস্ক। কোনো গ্লো নেই। ফন্ট: Plus Jakarta Sans + Hind Siliguri (বাংলা)।
- **থিম**: লাইট ডিফল্ট, ডার্ক/সিস্টেম বেছে নেওয়া যায় (হেডারের বাটন বা Account Setting থেকে)।
- **ফুটার অপরিবর্তিত** — ফুটারের HTML ও CSS আগের সাথে হুবহু এক (`css/styles.css`-এ "FOOTER" মন্তব্যের
  নিচের ব্লক)। নতুন থিমের রঙ/ফন্ট যাতে ফুটারে না ঢোকে, সেজন্য ফুটার যে টোকেনগুলো পড়ে সেগুলো ওখানে
  আটকে (pin) রাখা আছে।
- বুকিং ফর্মে লগইন থাকলে নাম/ইমেইল/ফোন আগেই ভরা থাকে; ধাপ যাচাই আরও কড়া; ব্যাকগ্রাউন্ডে স্ক্রল-স্পাই
  (বর্তমান সেকশন হাইলাইট); পাসওয়ার্ড দেখা/লুকানো বাটন; মোবাইলে লগইন মডাল নিচ থেকে ওঠে।
- `sw.js` এখন নিজের ফাইলের জন্য **নেটওয়ার্ক-ফার্স্ট** (ডিজাইন আপডেট করলে ইউজার সাথে সাথে নতুনটা পায়),
  অফলাইনে ক্যাশ থেকে চলে। ক্যাশ ভার্সন `v4`।
- অ্যাডমিন প্যানেলও একই ডিজাইনে; ড্যাশবোর্ডের ওভারভিউ তালিকা এখন মোবাইলেও দেখায়।

## আগের আপডেটে যা এসেছিল


- **অ্যাডমিন প্যানেল** (`admin.html`) — সার্ভিস, পোর্টফোলিও, কেস স্টাডি, টেস্টিমোনিয়াল, টিম,
  স্ট্যাটস কাউন্টার, প্রাইসিং প্যাকেজ, FAQ — সবকিছু যোগ/এডিট/মুছে ফেলা ও ক্রম পরিবর্তন করা যায়,
  কোনো কোড না ছুঁয়ে।
- **বুকিং ম্যানেজমেন্ট** — সব অনুরোধ এক জায়গায়, সার্চ/ফিল্টার, স্ট্যাটাস আপডেট (নতুন →
  যোগাযোগ করা হয়েছে → চলমান → সম্পন্ন/বাতিল)।
- **ইউজার ম্যানেজমেন্ট** — কাউকে অ্যাডমিন অ্যাক্সেস দেওয়া/বাদ দেওয়া যায় UI থেকেই।
- **সাইট সেটিংস** — হিরো টাইটেল/সাবটাইটেল, WhatsApp নম্বর, SEO বিবরণ — কোড এডিট না করেই বদলানো যায়।
- সাইটের সব কন্টেন্ট এখন **Firestore থেকে লোড হয়** (আগে `js/data.js`-এ হার্ডকোড করা ছিল)।
  `js/seed-data.js` এখন শুধু "ডিফল্ট কন্টেন্ট বসান" বাটনের জন্য নমুনা ডেটা হিসেবে আছে।
- ডিজাইন আরও ঝকঝকে করা হয়েছে — অ্যাভাটার সিস্টেম (ছবি/অক্ষর ফলব্যাক), বুকিং স্ট্যাটাস ব্যাজ,
  খালি-অবস্থার (empty state) আইকন, লোডিং স্কেলিটন — সব একই ডিজাইন টোকেন থেকে, কোনো
  গ্লো/শ্যাডো-হ্যালো ইফেক্ট ছাড়া।
- প্রোফাইল পেজ এখন একটা ছোট অ্যাকাউন্ট ড্যাশবোর্ড — মোট/চলমান/সম্পন্ন অনুরোধের সংখ্যা, আর
  অ্যাডমিন হলে সেখান থেকেই অ্যাডমিন প্যানেলের লিংক।
- সব ডাইনামিক টেক্সট এখন HTML-escape করে বসানো হয় — কারো লেখায় `&`, `<`, `>` থাকলেও
  লেআউট ভাঙবে না, আর পাবলিক বুকিং ফর্ম থেকে stored XSS-ও ঠেকানো হয়েছে।
- `sw.js`-এর অফলাইন cache লিস্টে `auth.js`/`firebase-config.js` বাদ পড়েছিল — সেটা ঠিক করা হয়েছে
  (আগে অফলাইনে প্রথমবার শেল ক্যাশ হলেও অ্যাপ ঠিকভাবে চলত না)।
- **`firestore.rules` এখন এই Firebase প্রজেক্টের বিদ্যমান রুলসের (কোর্স/এক্সাম/ডিসকাশন সাইট)
  সাথে merge করা** — আগে দেওয়া সংস্করণ নতুন করে বসালে ঐ সব রুলস মুছে যেত। অ্যাডমিন-স্ট্যাটাসও
  এখন সেই অ্যাপগুলোর সাথে মিলিয়ে `users/{uid}.isAdmin` (boolean) ব্যবহার করে — আলাদা `role`
  ফিল্ড আর নেই।

## Firestore কালেকশন

> এই Firebase প্রজেক্টে (`tvsaccount`) TechnicalSky-এর অন্য অ্যাপও (কোর্স হাব, এক্সাম সাইট,
> ডিসকাশন ফোরাম ইত্যাদি) চলে — তাই অ্যাডমিন-স্ট্যাটাস সেই অ্যাপগুলোর সাথে **একই স্কিম**
> ব্যবহার করে: `users/{uid}` ডকুমেন্টে `isAdmin` (boolean) `true`। আলাদা কোনো `role` ফিল্ড
> নেই — যাদের ইতিমধ্যে `isAdmin: true` আছে (অন্য অ্যাপের অ্যাডমিন), তারা এই সাইটের
> অ্যাডমিন প্যানেলও ব্যবহার করতে পারবেন, আলাদা করে কিছু সেট করা লাগবে না।

| কালেকশন | কী আছে | কে লিখতে পারে |
|---|---|---|
| `services`, `portfolio`, `caseStudies`, `testimonials`, `team`, `stats`, `pricingPlans`, `faqItems` | সাইটের কন্টেন্ট, প্রতিটা ডকুমেন্টে একটা `order` নম্বর | শুধু অ্যাডমিন |
| `settings/site` | হিরো টেক্সট, WhatsApp নম্বর, SEO বিবরণ, `codeUrl`/`courseUrl` (একটামাত্র ডকুমেন্ট) | শুধু অ্যাডমিন |
| `users/{uid}` | নাম, ফোন, `bio`, ছবি (`photoURL` বা আপলোড করা `avatarData`), `isAdmin` (boolean) | নিজের প্রোফাইল ফিল্ড নিজে, `isAdmin` শুধু অ্যাডমিন |
| `bookings/{id}` | বুকিং ফর্মের ডেটা + `status` | তৈরি: যে কেউ · পড়া: মালিক/অ্যাডমিন · আপডেট/মুছা: শুধু অ্যাডমিন |

## সেটআপ

Firebase প্রজেক্ট (`tvsaccount`) ও কনফিগ আগে থেকেই `js/firebase-config.js`-এ বসানো আছে।
নিচের ধাপগুলো [Firebase Console](https://console.firebase.google.com/) থেকে করতে হবে:

### ১. Authentication
Authentication → Sign-in method-এ গিয়ে **Email/Password**, **Google**, **GitHub** — এই তিনটা
প্রোভাইডার চালু আছে কিনা দেখে নিন (GitHub-এর জন্য GitHub OAuth App-এর Client ID/Secret লাগে)।

### ২. Security Rules বসানো — ⚠️ শুধু paste করবেন না, merge করুন
এই প্রজেক্টের Firestore-এ **আগে থেকেই** অন্য অ্যাপের (কোর্স/এক্সাম/ডিসকাশন) রুলস আছে।
Firebase Console → Firestore Database → Rules ট্যাবে যা আছে তা **সম্পূর্ণ প্রতিস্থাপিত হয়**
যা paste করবেন তা দিয়ে — তাই কখনো আংশিক rules paste করবেন না, নয়তো অন্য অ্যাপ ভেঙে যাবে।

এই রিপোর `firestore.rules` ফাইলটা ইতিমধ্যে **merge করা** — আপনার আগের সব রুলস
(courses, exams, discussions, coupons, flashcards ইত্যাদি) হুবহু অক্ষত রেখে শুধু Tech
Verse-এর নতুন কালেকশনগুলো (services, portfolio, bookings ইত্যাদি) যোগ করা হয়েছে, একই
`isAdmin()` ফাংশন পুনর্ব্যবহার করে। পুরো ফাইলটাই কপি করে Rules ট্যাবে paste করে
**Publish** করুন। (Firebase CLI থাকলে `firebase deploy --only firestore:rules`।)

যদি ভবিষ্যতে অন্য কোনো অ্যাপের জন্য আবার rules বদলাতে হয়, সবসময় **পুরো ফাইল** থেকে শুরু
করবেন (Firebase Console থেকে বর্তমান rules কপি করে রাখুন, বা এই রিপোর rules ফাইল আপডেট
রাখুন) — কখনো একটা অ্যাপের rules আলাদাভাবে বসাবেন না।

### ৩. কম্পোজিট ইনডেক্স — এটাও merge-সংবেদনশীল
প্রোফাইল পেজে "আমার অনুরোধসমূহ" লোড করতে একটা কম্পোজিট ইনডেক্স লাগে (`bookings`: `uid` +
`createdAt`)। এই রিপোর `firestore.indexes.json`-এ শুধু এই একটা ইনডেক্স আছে।

⚠️ যদি আপনার অন্য অ্যাপের জন্য (results, purchaseRequests ইত্যাদি) আগে থেকেই কোনো
`firestore.indexes.json` থাকে, তাহলে `firebase deploy --only firestore:indexes` চালানোর
আগে দুটো ফাইলের `indexes` অ্যারে **একসাথে মিলিয়ে** একটা ফাইলে আনুন — এই কমান্ডও rules-এর
মতোই পুরোনো ইনডেক্স মুছে ফেলতে পারে যদি ফাইলে না থাকে। নিশ্চিত না থাকলে সবচেয়ে নিরাপদ
পথ হলো CLI দিয়ে ডিপ্লয় না করে, সাইট ব্যবহার করার সময় Firebase নিজে যে "create index" লিংক
কনসোলে দেখায় (ব্রাউজার কনসোলে "The query requires an index...") সেটায় ক্লিক করে একটা একটা
করে ইনডেক্স তৈরি করা — এতে বিদ্যমান কোনো ইনডেক্স মোছে না।

### ৪. প্রথম অ্যাডমিন সেট করা
আপনার এই Firebase প্রজেক্টে যদি অন্য অ্যাপের (কোর্স হাব ইত্যাদি) জন্য ইতিমধ্যে কোনো
অ্যাডমিন অ্যাকাউন্ট (`isAdmin: true`) থাকে, সেই একই অ্যাকাউন্ট দিয়ে লগইন করলে Tech
Verse-এর অ্যাডমিন প্যানেলও সাথে সাথে খুলে যাবে — নতুন করে কিছু সেট করা লাগবে না।

একদম নতুন হলে, একবার ম্যানুয়ালি সেট করতে হয়:

1. সাইটে গিয়ে স্বাভাবিকভাবে **সাইন আপ** করুন (নিজের ইমেইল/Google/GitHub দিয়ে)।
2. Firebase Console → Firestore Database → `users` কালেকশনে গিয়ে নিজের ডকুমেন্টটা খুঁজুন
   (ইমেইল দেখে চেনা যাবে)।
3. `isAdmin` ফিল্ডটার ভ্যালু `false` থেকে `true` করে দিন (type: **boolean**)।
4. সাইটে রিফ্রেশ দিলে প্রোফাইল পেজে "অ্যাডমিন প্যানেল" লিংক দেখা যাবে।

এরপর থেকে অন্য কাউকে অ্যাডমিন বানাতে চাইলে অ্যাডমিন প্যানেল → ইউজার থেকেই করা যাবে,
Firebase Console-এ ফিরে যাওয়া লাগবে না।

### ৫. ডিফল্ট কন্টেন্ট বসানো
অ্যাডমিন প্যানেলে ঢুকে ড্যাশবোর্ডে "ডিফল্ট কন্টেন্ট বসান" বাটনে ক্লিক করলে নমুনা সার্ভিস,
পোর্টফোলিও, টিম ইত্যাদি একবারে Firestore-এ বসে যায় — এরপর সেখান থেকেই এডিট করে নিজের
আসল কন্টেন্ট বসিয়ে নেওয়া যায়। যেসব সেকশনে আগে থেকে কিছু আছে, সেগুলো এই বাটনে টাচ হয় না।

## লোকালি রান করা

`index.html` সরাসরি ব্রাউজারে (`file://`) খুললে ES module/Firestore কাজ করবে না — একটা
লোকাল সার্ভার লাগবে, যেমন:

```
npx serve .
```

বা VS Code-এর Live Server এক্সটেনশন দিয়ে।

## ডিপ্লয়

যেকোনো স্ট্যাটিক হোস্টিং (Firebase Hosting, Netlify, Vercel) দিয়ে ডিপ্লয় করা যায় — পুরো
ফোল্ডারটাই আপলোড করলেই হবে (`index.html` আর `admin.html` দুটোই থাকা জরুরি)। Firebase
Hosting ব্যবহার করলে:

```
firebase init hosting
firebase deploy
```

## কাস্টমাইজেশন নোট

- **হিরো টাইটেলে হাইলাইট রঙ:** অ্যাডমিন প্যানেল → সেটিংসে হিরো টাইটেলে কোনো অংশ
  `**এভাবে**` ডাবল-স্টার দিয়ে ঘিরে দিলে সেটা অ্যাকসেন্ট রঙে (ব্র্যান্ড নীল) হাইলাইট হয়ে দেখাবে।
- **ছবি:** পোর্টফোলিও/টিম/টেস্টিমোনিয়ালে ছবি দেখাতে চাইলে ছবির একটা পাবলিক URL বসাতে হবে
  (যেমন imgur, বা নিজের হোস্টিং থেকে) — ছবি না দিলে পোর্টফোলিওতে ক্যাটাগরি অনুযায়ী রঙিন কভার দেখায়।
  Firebase Storage যুক্ত করা হয়নি; শুধু ইউজারের প্রোফাইল ছবি ছোট করে Firestore-এ সেভ হয় (উপরে দেখুন)।
- **রঙ বদলাতে:** সব রঙ `css/styles.css`-এর শুরুর টোকেন ব্লকে (`--accent`, `--blue-*`, `--mint-*` …)।
  একটা জায়গায় বদলালেই সাইট, স্লাইডার ও অ্যাডমিন — সবখানে বদলে যাবে (ফুটার ছাড়া, সেটা ইচ্ছাকৃতভাবে আটকানো)।
- **আইকন:** সার্ভিস কার্ডের আইকন একটা নির্দিষ্ট (কিন্তু বেশ বড়) তালিকা থেকে বেছে নিতে হয়
  (`js/icons.js`) — সবগুলো একই স্ট্রোক-স্টাইলে আঁকা, যাতে নতুন আইকন যোগ করলেও ডিজাইন না ভাঙে।
