> **অবস্থা:** ইমপ্লিমেন্ট ও (সম্ভাব্য সব উপায়ে) যাচাই সম্পন্ন — **ডিপ্লয় করা হয়নি**। ফিচার ২ শুরুর আগে আপনার অনুমোদন দরকার (শেষে "অনুমোদন-গেট" দেখুন)।

## ১. সারসংক্ষেপ

- **পাবলিক:** নেভে "Blog"; `#blog` (তালিকা: ফিচার্ড-স্ট্রিপ, ক্যাটাগরি-পিল, সার্চ, ৯টা করে Load More) ও `#blog/{slug}` (কভার, লেখক, তারিখ, পড়ার সময়, ট্যাগ, সূচিপত্র, কোড-কপি, শেয়ার, মন্তব্য, সম্পর্কিত লেখা)। লেখা Markdown → দুই-স্তরের নিরাপদ রেন্ডার।
- **অ্যাডমিন:** নতুন "ব্লগ" বিভাগ — লেখা (খসড়া/প্রকাশ/আনপাবলিশ/প্রিভিউ/মুছা, কভার-আপলোড), ক্যাটাগরি (নিরাপদ মুছা + রিঅ্যাসাইন), মন্তব্য-মডারেশন।
- **নিরাপত্তা:** rules-ই আসল প্রহরী: লেখক-পরিচয় প্রোফাইল থেকে, `publishedAt` সার্ভার-সময়, স্লাগ-ইউনিকনেস অ্যাটমিক (ক্লেইম-ডক), মন্তব্য আগাম-অনুমোদিত + ২০ সেকেন্ড throttle, খসড়া/অননুমোদিত মন্তব্য পাবলিকের কাছে অদৃশ্য।
- **এক নজরে সংখ্যা:** নতুন JS ≈ ২,৪০০ লাইন (পাবলিক ≈ ১,৫৭০ + অ্যাডমিন ≈ ৮২০), CSS ≈ ১৯০, rules +≈ 225 লাইন, টেস্ট-কোড ≈ ২,৪০০ লাইন। পাবলিকের সবসময়-লোড অংশ শুধু `blog-entry.js` (≈ ৬ KB); বাকি ব্লগ-কোড `#blog` খুললেই লোড হয়। **কোনো লাইব্রেরি/বিল্ড-স্টেপ/ফ্রেমওয়ার্ক যোগ হয়নি।**

## ৩. Firestore স্কিমা (সব `tvProject/main/` এর নিচে) — *বাস্তব বদল*

### `blogPosts/{postId}` (আইডি স্থায়ী, অটো-আইডি; স্লাগ আলাদা ক্ষেত্র)
| ক্ষেত্র | টাইপ | নিয়ম |
|---|---|---|
| `title` | string | ৩–১৬০ |
| `slug` | string | `[a-z0-9]+(-[a-z0-9]+)*`, ≤৮০; **ইউনিক** (ক্লেইম-ডক) |
| `slugHistory` | list | ≤১০; পুরোনো স্লাগ → নতুনে রিডাইরেক্ট |
| `excerpt` / `content` | string | ০–৪০০ / ১–১০০,০০০ |
| `contentFormat` | string | শুধু `"markdown"` (অপরিবর্তনীয়) |
| `coverImage` / `coverAlt` | string | `http(s)` URL বা ফাঁকা (≤২০৪৮) / ≤২০০ |
| `category` | string | `[a-z0-9-]{1,40}`; `blogCategories/{id}` থাকতে হবে |
| `tags` | list | ≤১০ (প্রতিটা ≤৩০ — ক্লায়েন্টে) |
| `status` | string | `draft` \| `published` |
| `language` | string | `bn` \| `en` |
| `author`, `authorAvatar` | string | **তৈরির সময় অ্যাডমিনের নিজের `users/{uid}` প্রোফাইলের সাথে মিলতে হয়; পরে অপরিবর্তনীয়** |
| `createdBy`, `updatedBy` | uid | `== request.auth.uid` |
| `createdAt`, `updatedAt` | timestamp | `== request.time` |
| `publishedAt` | timestamp\|null | প্রথম প্রকাশে `request.time`; আনপাবলিশ/রিপাবলিশে আগেরটা থাকে; খসড়া-তৈরিতে `null` |
| `featured`, `featuredOrder` | bool, number | ০–৯৯৯৯ (ছোট আগে) |
| `commentsOpen` | bool | মন্তব্য নতুন করে নেওয়া যাবে কিনা |
| `readingTime` | int | ১–২৪০ (ক্লায়েন্টে ২০০ শব্দ/মিনিট) |
| `seoTitle`, `seoDescription` | string | ≤১২০ / ≤৩২০ |
| `searchTokens` | list | ≤৩০০ — শিরোনাম+ট্যাগের শব্দ ও ২–১৫ অক্ষরের প্রিফিক্স |

### `blogSlugs/{slug}` = `{ postId, createdAt }` — স্লাগ-ইউনিকনেস ক্লেইম (শুধু অ্যাডমিন; কখনো আপডেট নয়; শুধু পোস্ট ছেড়ে দিলে/মুছলে ডিলিট)
### `blogPosts/{postId}/comments/{commentId}` = `{ uid, authorName, authorAvatar, body(২–১৫০০), status, createdAt, updatedAt }` (+ মডারেশনে `moderatedBy`, `moderatedAt`)
`status`: `pending` (শুরু) → `approved` / `hidden` / `deleted`
### `blogCommentThrottle/{uid}` = `{ lastAt }` — ২০ সেকেন্ড ব্যবধান (শুধু লেখা)
### `blogCategories/{slug}` = `{ name(১–৪০), order, active, createdAt }` (কমিউনিটির ক্যাটাগরি-নিয়মই পুনর্ব্যবহৃত; **আলাদা কালেকশন** — কমিউনিটির `categories` ছোঁয়া হয়নি)

### ইনডেক্স (`firestore.indexes.json`, +৮)
| কালেকশন | ফিল্ড | কোন কোয়েরি |
|---|---|---|
| blogPosts | status↑, publishedAt↓ | তালিকা |
| blogPosts | status↑, category↑, publishedAt↓ | ক্যাটাগরি-ফিল্টার + সম্পর্কিত লেখা |
| blogPosts | status↑, searchTokens∋, publishedAt↓ | সার্চ |
| blogPosts | status↑, category↑, searchTokens∋, publishedAt↓ | সার্চ + ক্যাটাগরি |
| blogPosts | status↑, featured↑, featuredOrder↑ | ফিচার্ড |
| blogPosts | status↑, slugHistory∋ | পুরোনো স্লাগ-রিডাইরেক্ট |
| blogPosts | status↑, updatedAt↓ | অ্যাডমিন-তালিকা (ফিল্টারসহ) |
| comments | status↑, createdAt↑ | অনুমোদিত মন্তব্য / অ্যাডমিন-কিউ |

**মাইগ্রেশন: দরকার নেই** — সবকিছু নতুন কালেকশন; কোনো বিদ্যমান ডেটা/পাথ বদলায়নি।
**ভবিষ্যৎ (প্রস্তাব, এখন বাস্তবায়িত নয়):** `translations`, ক্যাটাগরির স্থানীয় নাম (ফিচার ৬)।

### যা rules নিজে বাধ্য করে (ক্লায়েন্ট-চেক নয়)
- লেখক-পরিচয় (`author`/`authorAvatar`/`createdBy`) জাল করা যায় না; `createdAt/updatedAt/publishedAt` সার্ভার-সময়; `status` শুধু `draft|published`।
- **স্লাগ-ইউনিকনেস:** একই batch-এ `blogSlugs/{slug}` ক্লেইম (`getAfter` দিয়ে মেলানো); খসড়া ও পুরোনো (history) স্লাগও সংরক্ষিত।
- মন্তব্য: `status` শুরুতে শুধু `pending`; লেখকের নাম/ছবি প্রোফাইল থেকে; `communityBlocked` ব্লক; throttle-ডক একই batch-এ `lastAt == request.time`; **কোনো সম্পাদনা নেই** (অনুমোদনের পর বিষয়বস্তু বদলানো অসম্ভব)।
- অনাথ-মন্তব্য শুধু পোস্ট মুছে যাওয়ার পর অ্যাডমিন পরিষ্কার করতে পারে।
- `storage.rules`: ডিফল্ট-ডিনাই; `blog/covers/{file}` — পাবলিক-পড়া, লেখা শুধু অ্যাডমিন (`firestore.get(users/{uid}).isAdmin`), jpeg/png/webp, ≤২ MB, নিরাপদ ফাইলনাম, আপডেট নিষিদ্ধ।

### রেন্ডার-নিরাপত্তা (XSS)
লেখার `content` Markdown; **কাঁচা HTML সমর্থিত নয়** (টেক্সট হিসেবে দেখায়)। (১) রেন্ডারার সব টেক্সট escape করে, ট্যাগ বানায় শুধু allowlist; লিংকে শুধু `http/https/mailto/#/রিলেটিভ`, ছবিতে শুধু `https`; (২) ফল আবার নিষ্ক্রিয় `<template>`-এ পার্স করে DOM-allowlist-এ ছাঁকা। শিরোনাম/সারসংক্ষেপ/লেখক/মন্তব্য সবসময় escape/`textContent`। JSON-LD `textContent` দিয়ে (`<` escape করা)।

### Trusted backend
**কোনো Cloud Function লাগেনি।** (ফিচার ২-এর "verified client" বা ফিচার ৩-এর অডিট-লগে লাগতে পারে — তখন আলাদা সিদ্ধান্ত।)

### বাকি সীমাবদ্ধতা (সৎ তালিকা)
1. **স্প্যাম:** rules দিয়ে সম্পূর্ণ ঠেকানো যায় না। এখন আছে: আগাম-অনুমোদন + ২০ সেকেন্ড throttle + `communityBlocked`। **App Check এখনো প্লেসহোল্ডার — চালু করুন** (`js/firebase-config.js`)।
2. **ক্যাটাগরি-মুছায় নির্ভরশীলতা-চেক ক্লায়েন্ট-সাইড** (rules কাউন্ট করতে পারে না); rules শুধু নিষ্ক্রিয় ক্যাটাগরি মুছতে দেয়। রেসে (মুছার মুহূর্তে অন্য অ্যাডমিন নতুন লেখা বানালে) লেখা এতিম ক্যাটাগরি-স্লাগ নিয়ে থেকে যেতে পারে — UI স্লাগ থেকে নাম বানিয়ে দেখায়, ভাঙে না।
3. মন্তব্যে **"রিপোর্ট" বাটন নেই** — আগাম-অনুমোদন + অসম্পাদনযোগ্য মন্তব্য থাকায় (বিস্তারিত §৯) এটি "প্রযোজ্য নয়" ধরা হয়েছে; দরকার হলে `reports`-এ `blogComment` টাইপ যোগ করা যাবে।

|---|---|

**ব্রাউজার-স্যুট কীভাবে "আসল":** Playwright + Chromium; Firebase SDK মক, কিন্তু প্রতিটা read/query/write Node-এ যায় যেখানে **আসল `firestore.rules`** চলে; কম্পোজিট-ইনডেক্স না থাকলে `failed-precondition` (আসল Firestore-এর মতো)। তাই UI-র আসল কোয়েরি/লেখা সরাসরি আমাদের rules + indexes-এর বিরুদ্ধে প্রমাণিত — ইনডেক্স-অনুপস্থিতির ত্রুটি ০।

**যা পরীক্ষায় ধরা পড়ে ঠিক করা হয়েছে (আসল বাগ):**
1. rules: একই অ্যাডমিন নিজের পোস্ট এডিট করলে `updatedBy` অপরিবর্তিত থাকে, অথচ rule তা "বদলাতে হবে" দাবি করত — সব এডিট আটকে যেত (rules-টেস্টে ধরা)।
2. `normalizeTags`: কমার পরের স্পেসসহ `" #Web"` থেকে `#` বাদ যেত না (ব্রাউজার-টেস্টে ধরা)।
3. Load More: ক্যারসর-রেসে ডুপ্লিকেট (ডিডুপ + `size+1` পদ্ধতিতে "আর নেই" আগে জানা)।
4. সাইটের `html{scroll-behavior:smooth}` নতুন "পাতা" খুললে স্ক্রল অ্যানিমেট করত — তাৎক্ষণিক লাফে ঠিক।
5. mutation-check: ২৬টা টেস্ট-ফাঁক (একটা শর্ত আলাদা করে পরীক্ষা হচ্ছিল না) + একটা অপ্রয়োজনীয় শর্ত সরানো।

## ৬. ম্যানুয়াল টেস্ট (ডিপ্লয়ের পর — আসল Firebase-এ)

**প্রস্তুতি:** ৩টা অ্যাকাউন্ট — (ক) অ্যাডমিন (`users/{uid}.isAdmin == true`, প্রোফাইলে **নাম** আছে), (খ) সাধারণ সদস্য, (গ) ব্লকড সদস্য (`communityBlocked: true`)।

1. **অ্যাডমিন → ব্লগ → ক্যাটাগরি:** "ডিফল্ট ক্যাটাগরি বসান" (বা নিজের বানান)।
2. **নতুন লেখা:** বাংলা শিরোনাম (স্লাগ `post-…` ফলব্যাক) → ইংরেজি স্লাগ দিন; ক্যাটাগরি, সারসংক্ষেপ, বিষয়বস্তু (`##` হেডিং, তালিকা, কোড-ব্লক, টেবিল, ছবি), ট্যাগ; "প্রিভিউ"; "খসড়া সংরক্ষণ"। **একটা ১৫০০-অক্ষরের বাংলা মন্তব্য** (নিচে ৭) অবশ্যই চেষ্টা করুন — rules-এর `size()` অক্ষর-গণনা আসল Firestore-এ যাচাই।
3. অতিথি/অন্য ব্রাউজারে `…/#blog/স্লাগ` → "পাওয়া যায়নি" (খসড়া অদৃশ্য)। অ্যাডমিন-সেশনে একই লিংক → "খসড়া প্রিভিউ" ব্যানার।
4. **প্রকাশ করুন** → পাবলিকে `#blog`-এ আসে; কার্ড/লেখা/SEO-মেটা (ব্রাউজার-ট্যাবের শিরোনাম)।
5. **স্লাগ বদলান** (প্রকাশিত লেখায়) → পুরোনো লিংক খুলে দেখুন নতুনে চলে যায়।
6. **ফিল্টার/সার্চ:** ক্যাটাগরি-পিল; সার্চে `fire` (প্রিফিক্স), বাংলা শব্দ, দুই শব্দ; দুটো একসাথে। **প্রথমবার** কোয়েরিতে "ইনডেক্স তৈরি হচ্ছে" ত্রুটি এলে `firebase deploy --only firestore:indexes` পুরো হওয়ার অপেক্ষা করুন।
7. **মন্তব্য:** সদস্যে লগইন → মন্তব্য → "অনুমোদনের অপেক্ষায়"; পরপর (২০ সেকেন্ডের মধ্যে) আরেকটা → বার্তা আসে; ব্লকড-সদস্য মন্তব্য করতে পারে না; **অ্যাডমিন → ব্লগ → মন্তব্য** → অনুমোদন → পাবলিকে দেখা যায়।
8. **ফিচার্ড:** লেখায় "ফিচার্ড" + ক্রম → ব্লগের ওপরের স্ট্রিপ।
9. **শেয়ার:** লিংক-কপি, WhatsApp, Facebook, X — আসল URL (`https://tvsites.vercel.app/#blog/…`)।
10. **আনপাবলিশ → মুছা:** প্রকাশিত লেখায় মুছুন-বাটন নেই; আনপাবলিশের পর (খসড়ায়) মুছা → স্লাগ-ক্লেইম ও মন্তব্যসহ যায়।
11. **ক্যাটাগরি মুছা:** লেখা-ওয়ালা ক্যাটাগরিতে "মুছুন" → রিঅ্যাসাইন-ডায়ালগ।
12. **অফলাইন:** ডেভটুলে অফলাইন → `#blog` → ত্রুটি + "আবার চেষ্টা"; অনলাইনে ফিরলে নিজে থেকে লোড।
13. **মোবাইল (≈৩৭৫px):** তালিকা/লেখা/এডিটর/ড্রয়ার (☰ → Blog)।
14. **(ঐচ্ছিক) কভার-আপলোড:** Storage চালু ও `storage.rules` ডিপ্লয়ের পর (§৮) JPG/PNG/WebP আপলোড; ২ MB-এর বড় ছবি নিজে ছোট হয়ে যায়।

## ৭. পারফরম্যান্স ও অ্যাক্সেসিবিলিটি

- **কোড-স্প্লিট:** ব্লগ শুধু `#blog`-এ ডায়ামিক import; Firebase-মুক্ত `blog-entry.js` (≈ ৬ KB) সবসময় লোড। অ্যাডমিন-API পাবলিকে লোড হয় না; Storage SDK শুধু আপলোডে।
- **কোয়েরি:** প্রতিবার ≤১০টা ডক (৯+১ "আরও আছে?" প্রোব); সার্চে সার্ভারে `array-contains`, বাকি শব্দ ক্লায়েন্টে — পুরো কালেকশন কখনো মেমোরিতে নয়; ফিচার্ড আলাদা ৩-ডক কোয়েরি; সম্পর্কিত লেখা ৪-ডক।
- **লিসেনার:** কোনো `onSnapshot` নেই (সবই one-shot, তাই লিক নেই)। auth-লিসেনার ব্লগ ছাড়লে বন্ধ; চলমান লোড `token`-এ বাতিল (stale update নেই); ডুপ্লিকেট-হ্যান্ডলার নেই (একবারই `root`-এ ডেলিগেশন)।
- **কভার-ছবি:** `loading="lazy"` (লেখার পাতায় `fetchpriority=high`), `width/height` + `aspect-ratio` (CLS কম), ভাঙা URL → সুন্দর ফলব্যাক।
- **অফলাইন/PWA:** শেল-ফাইল SW-তে; ডেটা ক্যাশ হয় না (কমিউনিটির মতোই); লোড-ব্যর্থতায় ত্রুটি+retry, `online` ইভেন্টে স্বয়ংক্রিয় রিট্রাই।
- **a11y:** `h1` একটাই (লেখায়), হেডিং-স্তর লাফ নেই (টেস্টেড), `role=search`, লেবেল, `aria-pressed` চিপ, `aria-live` তালিকা/মন্তব্য, `aria-current` (নেভ + সূচিপত্র), দৃশ্যমান ফোকাস (কার্ড-লিংকে `::after` আউটলাইন), ভিউ-বদলে ফোকাস `h1`/`h2`-এ, মডালে ফোকাস-ট্র্যাপ + Esc + ফোকাস-ফেরত, সূচিপত্র-ক্লিক হ্যাশ ভাঙে না, কীবোর্ডে শেয়ার/কপি/টুলবার, `lang` অ্যাট্রিবিউট (bn/en), কনট্রাস্ট মাপা (লাইট ও ডার্ক, ১৩টা টেক্সট-ধরন): সর্বনিম্ন ৪.৫৮:১ (লাইট) / ৪.৭০:১ (ডার্ক) — সবই WCAG AA (≥৪.৫)। `prefers-reduced-motion`: সাইটের বিদ্যমান গ্লোবাল নিয়ম; সূচিপত্র-স্ক্রল reduced-motion-এ তাৎক্ষণিক।
- **নেভ:** ৮টা লিংক ৯০১–১১০০px-এ এক সারিতে (প্যাডিং সামান্য কমানো; ৯০১/৯৬০/১০২৪/১১০০/১১৮০px-এ মাপা — ওভারফ্লো ০)।

## ৮. ডিপ্লয়-চেকলিস্ট (**আপনার অনুমতি ছাড়া কিছুই ডিপ্লয় হয়নি**)

1. **Rules + ইনডেক্স:** `firebase deploy --only firestore:rules,firestore:indexes` — ⚠️ ইনডেক্স তৈরি হতে কয়েক মিনিট; সাইট ডিপ্লয়ের *আগে* করুন।
2. **(ঐচ্ছিক) Storage — শুধু কভার-আপলোডের জন্য:** Console → Storage → *Get started* (নতুন বাকেটে Blaze প্ল্যান লাগতে পারে — Console জানাবে); তারপর `firebase deploy --only storage` (প্রথমবার CLI cross-service IAM-এর অনুমতি চাইবে — *Yes*)। Storage ছাড়াও ব্লগ পুরোপুরি চলে (কভার-URL পেস্ট)।
3. **সাইট ডিপ্লয় (Vercel):** `sw.js` ক্যাশ-ভার্সন বেড়েছে — ব্যবহারকারীরা পরের ভিজিটে নতুন শেল পাবে।
4. **অ্যাডমিন:** প্রোফাইলে **নাম** আছে কিনা দেখুন (লেখার `author` = এই নাম)। প্রথমে ক্যাটাগরি বসান।
5. **App Check:** reCAPTCHA v3 সাইট-কী বসিয়ে চালু করুন (স্প্যাম-সুরক্ষা)।
6. **রোলব্যাক:** সাইট আগের ডিপ্লয়ে ফেরান; rules-এর ব্লগ-অংশ নিরীহ (নতুন কালেকশন, বিদ্যমান কিছুর সাথে জড়ানো নয়)।
7. **অফিশিয়াল Emulator-এ একবার:** `cd tests && npm i && npm test` (Java + firebase-tools লাগে) — আমার এনভায়রনমেন্টে চালানো যায়নি (§৯)।

## ৯. জানা সীমাবদ্ধতা / যা চালানো যায়নি

**চালানো যায়নি (অনুমান নয়, স্পষ্ট):**
- **অফিশিয়াল Firebase Emulator / লাইভ Firebase** — এই এনভায়রনমেন্টে নেটওয়ার্ক/Java নেই। rules যাচাই হয়েছে প্রজেক্টের নিজস্ব অফলাইন-সিমুলেটরে (যা অফিশিয়াল নয়; unsupported সিনট্যাক্সে ফেল করে বলে সংরক্ষণশীল)। **ডিপ্লয়ের আগে §৮.৭ ও §৬ চালান।**
- **Firebase Storage আপলোড** — শুধু মক-SDK-তে (পাথ/টাইপ/ত্রুটি-বার্তা যাচাই); আসল আপলোড/rules আনটেস্টেড।
- **Safari/Firefox/আসল ডিভাইস, স্ক্রিন-রিডার, Lighthouse, axe-core** — চালানো যায়নি (Chromium-এ কাঠামোগত a11y-চেক ও কনট্রাস্ট-মাপ করা হয়েছে)।
- Google Analytics/কুকি-ব্যানার — এই ফিচারের আওতার বাইরে।

**ডিজাইন-সিদ্ধান্ত ও সীমা:**
1. **SEO:** hash-routing-এ `#blog/…` সার্ভারে যায় না — ফেসবুক/WhatsApp প্রিভিউ ও অনেক ক্রলার হোমপেজের মেটা দেখে; আলাদা ইনডেক্সযোগ্য URL-এর জন্য প্রিরেন্ডার (ডিপ্লয়-টাইম জেনারেটর) বা History-API + `vercel.json` রিরাইট লাগবে — **ফিচার ৪-এ** (বিল্ড-স্টেপ ছাড়া Node-স্ক্রিপ্ট হিসেবে) প্রস্তাবিত। এই ফিচার ক্লায়েন্ট-সাইডে সঠিক মেটা/JSON-LD বসায় (JS-চালানো ক্রলার ও ব্রাউজার-ট্যাবের জন্য)। `sitemap.xml` অপরিবর্তিত।
2. **সার্চ** শিরোনাম-শব্দ ও ট্যাগের প্রিফিক্স-ম্যাচ; লেখার বডিতে ফুল-টেক্সট নয় (Firestore-এ সম্ভব নয়; বাহ্যিক সার্ভিস লাগবে)।
3. **মন্তব্য আগাম-অনুমোদিত (pending)** — spec: "শুধু approved দেখাবে"। সার্বজনীন-প্রকাশ চাইলে শুধু `blogCommentStartStatus()` (rules) ও `COMMENT_START_STATUS` (`model.js`) বদলান; contract-টেস্ট দুটোর মিল যাচাই করে।
4. **মন্তব্য-রিপোর্ট নেই** (§৪.৩)।
5. **লেখক = তৈরিকারী অ্যাডমিন** (নাম/ছবি প্রোফাইল থেকে)। "টিমের নামে" লেখা চাইলে আলাদা `authorProfiles` দরকার — প্রস্তাব, বাস্তবায়িত নয়।
6. `authorAvatar` প্রতিটা পোস্ট-ডকে (≤১২,০০০ অক্ষর থাম্বনেইল) — তালিকা-পেজে ~১০০ KB পর্যন্ত বাড়তে পারে; ভবিষ্যতে `authors` সংগ্রহে আনা যায়।
7. রিচ-টেক্সট/HTML সমর্থিত নয় (ইচ্ছাকৃত — নিরাপত্তা); এম্বেড (ভিডিও) নেই।
8. `translations`/ক্যাটাগরির স্থানীয় নাম — ফিচার ৬।
9. এডিটরের "অসংরক্ষিত পরিবর্তন" গার্ড সাইডবার-ক্লিকে `confirm()` (ব্রাউজার-ব্যাক-বাটনে আটকানো যায় না)।

## ১০. অনুমোদন-গেট

ফিচার ১ (ব্লগ/রিসোর্স) সম্পূর্ণ। **ফিচার ২ (লাইভ ক্লায়েন্ট রিভিউ ও রেটিং) শুরুর অনুমতি দিন** — আর তার আগে সম্ভব হলে §৮.৭ (অফিশিয়াল Emulator) ও §৬ (ম্যানুয়াল) একবার চালিয়ে দেখুন। ফিচার ২-তে "যাচাইকৃত ক্লায়েন্ট" ও রেটিং-অ্যাগ্রিগেশনের জন্য একটা সীমিত Cloud Function লাগার সম্ভাবনা আছে — শুরুতে আলাদা করে জানাব।
